# 🏡 Airbnb 

Airbnb is a full-stack web application inspired by the Airbnb platform, where users can explore properties, book stays, and host their own listings.  
This project is built to practice real-world MERN stack development, authentication, and booking workflows.

## ✨ Features
- User authentication (Sign up / Login)
- Property listing with image upload
- Host can add, update, and delete properties
- Booking system with date selection
- Secure APIs using JWT authentication
- Fully responsive UI

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

### Tools & Services
- Cloudinary (Image upload)
- Render (frontend & Backend deployment)
